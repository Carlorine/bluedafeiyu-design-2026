## 怎么参加

1. Fork 本仓库。
2. 新建文件夹 `submissions/你的GitHub用户名/`，放进你的网页，入口文件是 `index.html`。
3. 再放一个 `meta.json`（格式照抄 [submissions/_example/meta.json](submissions/_example/meta.json)）。
4. 提交 PR。页面能打开、内容和主题相关，就会被合并，合并后就算参与成功。

合并以后，截稿前可以随时再提 PR，修改你自己的文件夹。

不会用 Git 也没关系，把这段 README 丢给 AI，让它一步步教你 Fork 和提 PR 就行。

## 起步包

`starter/` 里是现成的素材，拿来就能开工：

| 文件 | 内容 |
| --- | --- |
| `starter/data.json` | 网站的公开数据：角色、分类、全部作品（名称、描述、标签、尺寸、图片地址） |
| `starter/data.js` | 同一份数据，写成 `window.SITE_DATA`，双击打开 HTML 时也能读到 |
| `starter/tokens.css` | 正式站的配色、字号、间距、圆角、阴影，以及每个角色的代表色 |
| `starter/PROMPTS.md` | 几句可以直接丢给 AI 的提示词 |

图片直接用数据里的地址（指向蓝色大肥鱼.com），不用下载。

在你的页面里可以直接引用起步包：

```html
<link rel="stylesheet" href="../../starter/tokens.css">
<script src="../../starter/data.js"></script>
```

也可以把需要的文件复制进自己的文件夹。示例投稿在 [submissions/_example/](submissions/_example/)。

起步包和示例只是给你参考数据怎么读、路径怎么写，**不代表要做成这个样子**。`tokens.css` 是现在网站的配色，用不用、改成什么都随你。
