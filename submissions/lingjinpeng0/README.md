# 蓝色大肥鱼 · AI 娘图库

一个极简风格的二创作品图库首页，直接打开 `index.html` 就能用（数据来自 `../../starter/`，所以要在仓库里打开；单独拷走这个文件夹是看不到作品的）。

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 主页面。样式、结构、脚本都在一个文件里，双击就能看，不依赖构建 |
| `meta.json` | 投稿信息（标题、作者、说明、包含的页面） |
| `logo.png` | 站点图标（本站 favicon 的缩小版，同时用作页面图标） |
| `topics.js` | 站点「合集 / 专题」快照（来源 `topics.json`，抓于 2026-10-02），离线也能看合集 |

## 都能干什么

- **浏览**：作品网格；点开是查看器（大图 + 说明 + 角色碎碎念），支持键盘 ← → 翻页、Esc 关闭
- **找**：搜索框（作品名 / 标签 / 角色名 / 描述，空格分词），左侧角色与分类，右侧按最新 / 乱序 / 竖图 / 横图排序
- **显示方式**：等大裁切（每行 4~8 张）或原比例（不裁切，按每件作品自己的宽高比排瀑布流）。三处入口——侧栏「显示」、排序栏下面那行、随机界面标题条——共用同一份设置，选择记在 `localStorage`
- **合集**：对应站点的专题（含作者专题），带专题头（来源作者、说明、件数、去正式站）
- **随机看看**：独立界面，一批抽「每行张数 × 3」件，可换一批重洗
- **外观**：6 套强调色 × 浅色 / 深色，收起的侧栏与宽度也会记住；滚过一屏出现回到顶部的按钮

## 已知的取舍

- 数据是构建时读的 `starter/data.js`，页面本身不联网；`topics.js` 是站点专题的一次性快照
- 图片直接用数据里的地址，所以离线打开时只有文字和骨架
- 原比例布局的列分配是脚本算的（按「当前最矮的一列」放），这样搜索结果很少时也会老老实实一行行排，而不是被 CSS 多列按高度均衡挤到一列里
