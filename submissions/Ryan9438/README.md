# 蓝色大肥鱼 · AI 娘二创开放档案（DeepSeek Chat 风格）

投稿人：[@Ryan9438](https://github.com/Ryan9438)

把 **DeepSeek 官网 Chat 界面**的排版语言，搬来做这个档案站的新前台。
入口只有一个 `index.html`，双击就能打开，不联网也能跑（图片才需要联网）。

## 跑起来

双击 `index.html` 即可。也可以起个静态服务器：

```bash
python -m http.server -d submissions/Ryan9438
```

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 全部内容：结构、样式、脚本、数据都在这一个文件里（约 715 KB）。零依赖，没有构建步骤 |
| `assets/fish.png` | 站内唯一的本地图片，取自官网 favicon，裁掉了透明边距 |
| `cover.jpg` | 展览页缩略图 |

作品数据（977 件）、角色代表色、合集、统计数字都在**构建时**从站点公开接口取好，内联进了 `index.html`。
运行时不再请求任何数据接口——官网接口没有 CORS 头，直接 fetch 会失败。图片仍然直接引用官网地址，没有下载。

## 对照 DeepSeek 界面做了什么

侧栏的这些数字不是估的，是从实拍截图里量出来再还原的：

- **行距 / 字号 = 2.88** → 14px 字配 40px 行高
- **分组标签字号 = 条目的 0.81** → 11.5px；亮度约为条目的 71%；上留 23px 的呼吸感（对应 DeepSeek 的「昨天」）
- **选中态只有一层灰底**（`#343638`，圆角 10px），文字不变色也不加粗
- **侧栏宽 268px**；角色子级限高 300px 内滚，保证下面的「合集 / 社群 / 最新活动」永远不被推出屏幕

底部的输入框就是全站搜索框：输入即筛选（140ms 防抖），右边的「类型 / 排序」胶囊向上弹出菜单，右上是发送键。
左上角的放大镜会把光标直接送进这个输入框。

## 做了什么

- **全部作品**：24 张一屏地增量渲染 + 无限滚动；按名称 / 角色 / Tag 搜索；类型与排序（最新 / 最热 / 下载最多，用的是真实统计数字）
- **角色筛选**：点侧栏角色即筛，选中态是「角色分组 + 具体角色」两级高亮，任何时候侧栏只有一处亮
- **图片查看器**：主体栏 + 周边虚化。切换时先用缩略图虚化打底 + 转圈遮住旧图，新图解码完再淡入（不然会出现「右边信息栏先变、图片后变」）；预取前后各两张。右栏是大肥鱼说、简介、下载原图、来源与收录状态、标签
- **合集**：列表页 + 合集详情两层，详情里有作者 / 类型 / 排序三个下拉，默认按专题精选顺序
- **社群 / 最新活动 / 投稿 / 关于与版权 / 推荐** 五个页面。投稿页不做假表单——静态页提交不了，所以它把**三条真实通道**（站内表单 / GitHub Issue 表单 / QQ 群）聚合成主入口
- **黑白双主题**：色值从实拍图里取，选择记在 `localStorage`，并在 `<head>` 里提前应用，所以刷新不会闪一下
- **收起侧栏**：整条滑出，主区补满；`Cmd/Ctrl+B` 也能切；左下角「⋯」向上弹出站点信息菜单

## 一些取舍

- **不联网也要能用**：数据内联，图片走官网。所以文件偏大（约 715 KB），换来的是双击就能看。
- **外部权威内容一律新标签打开**：规则、QQ 群、GitHub 表单、官网页面共 28 个外链；站内页只保留不会变的事实。
- **移动端**：侧栏在窄屏下是浮层，收起后主区不再留出 268px。

## 已知的没做

- 站内评论（官网是 GitHub Discussions / Giscus 托管的，静态投稿页接不了）
- 多语言（官网有四套界面语言，这里只做简体中文）
- 站内投稿表单（原因见上）
