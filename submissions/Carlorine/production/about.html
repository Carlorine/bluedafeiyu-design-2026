关于

蓝色大肥鱼是一个非官方同人整理项目，讲清楚它是干什么的、版权归谁、以及我们不收集你的哪些数据。

关于本站

「蓝色大肥鱼」是收集 AI 娘二创表情包的开放档案：作品按角色归档，支持按名称、Tag 与角色别名检索；每张作品都有独立详情页，可以查看来源与授权、下载原图，还带一个独立的评论区。更新日志见页脚。

你能在这里做的事：按角色与分类浏览全部作品；用关键词搜名称、Tag 或别名；进详情页拿原图；在作品下留言讨论；也可以把自己的作品投稿进来。

许可与版权

本站的程序代码以 MIT 协议发布，随便用。

但投稿或被收录的表情包不会因为进了本站仓库就自动获得 MIT 授权——图片的著作权始终归原作者所有。能不能用、怎么用，以每张作品详情页标注的来源与授权为准。

标注为「授权状态不明」的作品，请先联系原作者取得许可，勿直接商用。

统计与隐私

  • 本站使用 Google Analytics 4 统计聚合的页面访问、来源、设备与性能数据，用于发现加载问题和改进页面；Google 可能设置第一方分析 Cookie。
  • 广告个性化、Google Signals 与广告存储均已关闭；本站不建立账号画像，不把统计数据做成作品热度分或排行榜。
  • Google Fonts 会从 Google 字体服务加载；评论托管在 GitHub Discussions，本站不自行保存评论者身份。

评论

评论由 GitHub Discussions（Giscus）托管，需要登录 GitHub 账号才能发言；一张作品对应一个独立讨论串，互不串台。

署名与删除

原作者需要补署名、修改来源信息或下架作品，走 GitHub 上的「署名与删除申请」表单，维护者会尽快处理。

收到有效的版权投诉后，会先下架相关作品，再核实情况。
